# Project Statement

## Problem Statement
Managing gym member details, membership plans, payments, and renewals manually can make records difficult to maintain. This project provides a simple command-line system to organize these activities.

## Scope
The system manages member information, membership plans, payment status, renewals, and basic reports using Python and JSON storage.

## Target Users
- Small gym owners
- Gym reception staff
- Gym administrators

## High-Level Features
1. Member Management
2. Membership and Payment Management
3. Reports and Analytics
4. Persistent JSON data storage
5. Input validation and error handling
